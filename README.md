# Intern Radar

My internship board: SWE and CS intern roles from about 4,000 company job boards, startups first and big tech on the side, with phone alerts for new ones.

**Board:** https://zhenghchen.github.io/intern-radar/

What counts as a match is set in `config/profile.yaml`; the big-tech watchlist and extra companies are in `config/companies.yaml`.
